## Output contract

All keys required: document {fileName:string, pages:positive integer, language:ISO639-1, type: faktura|umowa|oferta|raport|inne, title:string, date:ISO8601 date|null}; summary:string (3–5 factual sentences in document language); keyPoints:string[] (3–7); entities {organizations:string[], people:string[]}; amounts:[{value:finite number,currency:ISO4217,context:string}]; dates:[{date:ISO8601 date,context:string}]; keywords:string[]. Missing collections [], missing main date null. Missing title should be deterministic neutral label in document language, documented as fallback, never a fabricated title. Input filename/page count set by server from validated request, not generated by AI. No empty strings as valid facts. Abbreviations/decimal points make naive sentence-splitting unreliable: document your validation approach. Insufficient source facts should lead to useful error, not invented key points.
